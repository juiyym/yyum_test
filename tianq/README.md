# 天气查询应用 (tianqi_yym)

一个简洁美观的天气查询 Web 应用，使用 HTML + CSS + JavaScript 构建。

## 功能特性

- 🌤️ 实时天气查询
- 🎨 现代化 UI 设计
- 📱 响应式布局，支持移动端
- 💾 本地存储，记住上次查询的城市
- ⚡ 流畅的动画效果
- 🔍 快速搜索功能

## 项目结构

```
.
├── index.html      # 主 HTML 文件
├── style.css       # 样式文件
├── script.js       # JavaScript 逻辑
└── README.md       # 项目说明
```

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 在搜索框中输入城市名称
3. 点击搜索按钮或按回车键查询天气

## 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和动画
- **JavaScript (ES6+)** - 交互逻辑

## 注意事项

当前版本使用模拟数据。如需使用真实天气 API，请：

1. 注册 [OpenWeatherMap](https://openweathermap.org/api) 获取 API Key
2. 在 `script.js` 中替换 `apiKey` 变量
3. 取消注释真实的 API 调用代码
